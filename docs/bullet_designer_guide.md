# 弹幕设计指南（设计师版）

> 面向游戏设计师 / 关卡策划。不讲代码，只讲"你想要什么效果，就调什么旋钮"。
> 项目内另有面向开发者的《弹幕系统使用说明》（`docs/bullet_system_usage.md`）。

## 一个弹幕 = 三件事

任何一个弹幕都可以拆成三件事，分别控制"长什么样"、"什么时候发"、"发完怎么飞"：

| 维度 | 问的是 | 设计师关心 |
|---|---|---|
| 形状 | 一轮子弹排成什么图形？ | 圆环 / 花瓣 / 扇形 / 一圈点 |
| 节奏 | 每轮间隔多久？共几轮？ | 密度、疏密、总时长 |
| 运动 | 子弹飞出去之后怎么动？ | 直线飞 / 先炸开再巡航 / 绕圈飞 |

改任何一个维度，弹幕的性格就变了。三者互相独立，可以随意组合。

---

## 一、形状：子弹怎么摆

**圆环**：最基础的弹幕形状。调"半径"控制离中心多远，"起始角度"控制从哪开始排。

**花瓣**：在圆环基础上做"花瓣"变形（极坐标公式），"花瓣数"越多越密集。经典玫瑰形弹幕。

**扇形**：只取圆环的一部分，比如 1/4 或 1/2 段。适合"朝一个方向集中压制"。

**一点**：所有子弹从同一点发出，配合方向发散（见"方向"）形成散弹。

**复合形状**：多个形状叠在一起（加法合并），比如"大环套小环"一屏出两组。

> 调参手感：半径决定弹幕"铺多开"；子弹数决定"密不密"；起始角度决定第一眼朝向。

---

## 二、节奏：什么时候发

**轮次**：发几波。设成无限就是永不停歇（适合纯压制，需注意子弹量）。

**间隔**：两波之间的秒数。间隔越短越密集，越长越有"呼吸感"。

**初始等待**：进场后先停一下再发第一波，用来卡节奏或配合演出。

**每轮演化**（重点！）：

| 旋钮 | 效果 |
|---|---|
| 每轮旋转角度 | 每波比上一波转一个角度 → **旋转环 / 风车**（转得快像漩涡，转得慢像旋转栅栏） |
| 每轮半径增量 | 每波比上一波大一圈 → **螺旋 / 扩散环**（增量小是密螺旋，增量大是稀疏扩散） |

> 这两个旋钮是"让弹幕活起来"的关键。只调形状+节奏是静态版，加上演化才出"动态大杀器"。

---

## 三、运动：飞出去之后

| 运动 | 适合做什么 | 关键旋钮 |
|---|---|---|
| 直线飞 | 一切基础弹 | 速度、加速（加速=越飞越快） |
| 两段式 | 先爆发后减速的"炸裂感" | 爆发速度、爆发时长、巡航速度 |
| 沿曲线飞 | 绕圈 / 蛇形 / 螺旋弹 | 曲线形状、速度 |

> 手感要点：直线弹要"爽快"就拉高速度；要"压迫感"就加速；两段式适合"开场炸一下再慢悠悠飘"的恐怖弹。

---

## 四、方向：往哪飞

| 方向模式 | 效果 | 典型用途 |
|---|---|---|
| 沿形状切线 | 沿着圆环切线的方向飞 | 旋转环、风车 |
| 从中心向外 | 从中心辐射出去 | 扩散波、花朵 |
| 瞄准玩家 | 精确锁定玩家位置 | 狙击弹、扇形追踪 |
| 固定方向 | 全部朝同一方向 | 扫射、下雨 |
| 随机抖动 | 方向带随机偏移 | 弹幕幕墙、弹雨 |

**附加旋钮**：抖动角度。给任何方向加上"抖动量"，弹幕会从"规则"变"混乱"，常用于难度曲线末端。

---

## 五、套娃：子弹里藏子弹（进阶）

支持两层嵌套：**外层子弹飞出去之后，从它身上不断喷出内层子弹**。

典型用法：

> 外层母弹向下移动，内层每 0.1 秒从母弹当前位置喷出一圈子弹并向外扩散 → **一个向下移动且不断扩大的圆圈**。

设计师只需要定义两层各自的"形状 + 节奏 + 运动"，系统自动让内层跟着外层子弹跑。

## 六、想要的效果 → 怎么调（速查表）

| 想要的效果 | 形状 | 演化/方向 | 运动 |
|---|---|---|---|
| 旋转环（经典） | 圆环 | 每轮旋转 10° | 直线飞 |
| 螺旋（越转越大） | 圆环 | 每轮半径 +3 | 直线飞 |
| 玫瑰花瓣 | 花瓣 | 不演化 | 直线飞 |
| 瞄准扇形 | 扇形（朝玩家） | 方向=瞄准玩家 | 直线飞（快） |
| 扩散波（三环齐射） | 复合（三个环） | 每轮旋转 24° | 直线飞 |
| 炸裂两段（burst） | 圆环 | 不演化 | 两段式（先炸后飘） |
| 绕圈追踪 | 一点 | 方向=瞄准玩家 | 沿曲线飞 |
| 套娃扩散圈 | 外层一点 + 内层圆环 | 内层每轮旋转 | 外层直线 + 内层直线 |

2. 自动列出所有弹幕用例，← → 切换，R 重播，C 单曲循环，Tab 隐藏界面。
3. 想改效果：让开发同事在 `data/danmaku_tests/` 下复制一个用例，按上面的旋钮调参数即可，运行即时可见。

**建议调参顺序**：先定"形状"看整体 → 再加"演化"看动态 → 最后调"运动/方向"定手感。

## 八、给关卡用的搭配思路

- **开场**：慢速旋转环 + 长间隔 → 给玩家熟悉节奏的窗口。
- **中段**：花瓣 + 每轮旋转 + 随机抖动 → 制造视觉压力但不致死。
- **高潮**：瞄准扇形 + 两段式爆发 + 套娃 → 全屏压迫，逼玩家走位。
- **混合**：不同弹幕之间用"方向"区分（环形偏绕、扇形偏压、追踪偏点杀），避免同质化。
